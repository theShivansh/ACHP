## Earlier figures (not re-run here)

The project's earlier write-up reports 68.3% macro accuracy on its own factual, opinion and prediction claims. Those claims and runs are not in this repository, so the figures below are transcribed, not measured, and are never averaged with ACHP Bench.

| System | Factual | Opinion | Prediction | Macro |
|---|---|---|---|---|
| ClaimBuster SVM | 61.2% | 44.3% | 38.7% | 48.1% |
| GPT-4o zero-shot | 74.8% | 52.6% | 49.1% | 58.8% |
| Factiverse API | 78.3% | 55.1% | 52.4% | 61.9% |
| **ACHP (ours)** | 82.4% | 63.7% | 58.9% | 68.3% |
| **ACHP with a second debate round** | 84.1% | 65.2% | 60.4% | 69.9% |

| Configuration | Macro accuracy |
|---|---|
| Proposer only | 52.4% |
| + Adversary A | 60.8% |
| + Adversary B | 64.1% |
| + NIL (all five checks) | 67.9% |
| + Judge synthesis | 68.3% |
| + second debate round | 69.9% |

Every component added a gain reported as statistically significant (p < 0.01, McNemar's test).

- **Paper abstract and Sec. IX: 69.9%.** The same figure as the second-debate-round variant above.
- **Paper Table III per-benchmark mean: 62.2%.** Reported per benchmark as 74.8, 48.6 and 63.1, against a GPT-4 zero-shot mean of 57.2. Different benchmark sets from the table above; not reconciled.
